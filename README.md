# Selected projects

I build AI workflow demos and small software tools, with a focus on tool calling, traceable outputs, and evaluation.

### Creator Ops Agent

A creator-marketing demo with two approaches: a guided workflow for screening creators and drafting outreach, and a research agent that calls a small set of tools and cites its sources. The repository includes a mock mode, human review steps, and tests.

[Explore Creator Ops Agent](https://github.com/jackguo2016/creator-ops-agent)

### Graph coloring in Java

A coursework solver that combines constraint propagation, search heuristics, and backtracking to assign different colors to neighboring vertices. Includes sample graphs and JUnit tests.

[Explore the graph coloring solver](https://github.com/jackguo2016/CS6511_AI_Project2)

### Handwritten digit recognition

A Java k-nearest neighbors experiment using labeled MNIST images. Compares classification error across different values of K.

[Explore the MNIST experiment](https://github.com/jackguo2016/ML_KNN_digit-recognizer)
